# HTML - Proyecto Conquer Academy

Proyecto HTML multipágina basado en una academia ficticia llamada Conquer Academy.

## Requisitos trabajados

- `index.html` como página inicial.
- Enlaces relativos.
- Estructura organizada en carpetas.
- Header común.
- Footer común.
- Home.
- Quiénes somos.
- Cursos.
- Detalle de curso.
- Blog.
- Detalle de noticia.
- Registro.
- Login.
- Contacto.
- Aviso legal.
- Etiquetas semánticas.
- Meta title y meta description en cada página.
- Imágenes responsive en SVG.

## Estructura

```text
index.html
quienes-somos.html
cursos.html
blog.html
registro.html
login.html
contacto.html
css/
  styles.css
img/
  imagenes svg
cursos/
  curso-fullstack.html
  curso-data.html
blog/
  noticia-html-semantico.html
  noticia-portfolio.html
legal/
  aviso-legal.html
```
